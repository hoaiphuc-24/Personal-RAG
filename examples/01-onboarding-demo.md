# DEMO — Employee Onboarding Process

This is fictional work data for testing Personal AgenticRAG, not your organization's policy.

## First Day
New employees receive internal accounts from IT, enable two-factor authentication,
read the security guide, and meet their mentor. Do not share passwords in chat.

## First Week
The mentor introduces the project structure, review process, and test environment.
The new employee completes a small task, opens a pull request, and receives feedback.
At the end of the first week, the employee and manager discuss 30-day goals.

## Onboarding Checklist
1. Receive equipment and accounts.
2. Enable two-factor authentication.
3. Read the security guide.
4. Run the project in the test environment.
5. Open a first pull request and receive a review.
6. Agree on 30-day goals with the manager.
